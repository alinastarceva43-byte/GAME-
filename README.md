# 🎮  Руководство пользователя к игре "Найди пару" 

Добро пожаловать в игру на развитие зрительной памяти и внимательности! В этом руководстве подробно описаны правила игры, элементы интерфейса и игровой процесс.
##  Игровой процесс и правила

### Шаг 1. Исходное положение
При старте игры перед вами открывается синее квадратное поле, состоящее из **16 закрытых карточек** с черными контурами. Все скрытые значки изначально невидимы, так как цвет текста совпадает с цветом синего фона.

*Рисунок 1. Внешний вид игры в начале раунда.*

### Шаг 2. Открытие первой пары
Кликните левой кнопкой мыши по любой карточке — на ней отобразится скрытый символ (например, глаз). Затем попытайтесь найти такую же картинку, кликнув по второй карточке. 

 **Если значки совпали:** они останутся открытыми на экране до самого конца игры.

 <img width="394" height="427" alt="image" src="https://github.com/user-attachments/assets/e2ed2a8f-f8af-4526-b97e-a4e600575506" />

*Рисунок 2. Успешное открытие первой пары одинаковых значков.*

### Шаг 3. Несовпадающие карточки
Если вы кликаете по двум карточкам, а значки на них оказались **разными**, система покажет их вам ровно на одну секунду. После этого встроенный таймер автоматически закроет их обратно.

*Постарайтесь запомнить, где какая картинка находилась, чтобы использовать это при следующих ходах!*

<img width="437" height="522" alt="image" src="https://github.com/user-attachments/assets/7ea823bf-832c-4bfd-8b47-a48a455173ba" />

*Рисунок 3. Поиск пар на игровом поле.*

### Шаг 4. Поиск оставшихся картинок
Перебирайте карточки дальше, удерживая в памяти расположение уже увиденных ранее предметов (велосипедов, пауков, запрещающих знаков).

*Рисунок 4. Постепенное заполнение поля открытыми элементами.*

### Шаг 5. Полное открытие поля
Игра продолжается до тех пор, пока абсолютно все 16 ячеек таблицы не покажут свои скрытые символы. Всего на поле спрятано **8 уникальных пар**.


<img width="391" height="423" alt="image" src="https://github.com/user-attachments/assets/81a354b5-dc90-4dc7-9508-355aefd7c8e2" />

*Рисунок 5. Все пары успешно найдены.*

### Шаг 6. Победа!
Как только последняя пара совпадет, игра автоматически завершится и выведет на экран диалоговое окно с поздравлением: **«Congratulations! You matched all the icons!»**.

Чтобы закрыть игру, нажмите кнопку **ОК** в окне уведомления.
